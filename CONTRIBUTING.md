# Contributing Guide

Thank you for contributing to **AcademicIF Events**.

This repository was created for academic purposes in order to simulate a professional agile software development environment using Scrum, Kanban, and modern engineering tools.

---

# Project Goal

The system aims to assist in the organization of academic events by allowing the management of registrations, participants, lectures, workshops, and other institutional activities.

---

# Technologies and Tools Used

- GitHub
- Jira
- Confluence
- Discord

---

# Workflow

The project follows agile practices using Scrum and Kanban.

Tasks are organized in Jira using the following columns:

- Backlog
- To Do
- Doing
- Done

Before starting any development task:

1. Check the available tasks;
2. Select or receive an issue;
3. Update the task status in Jira;
4. Develop using a separate branch;
5. Open a Pull Request after finishing the implementation.

---
